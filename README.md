# SP Connect Argentina · archivos de la tienda

Videos de producto que se muestran en el carrusel de la tienda SP (Tiendanube).
Se sirven por jsDelivr:

`https://cdn.jsdelivr.net/gh/florluuucia/sp-tienda@main/productos/videos/<archivo>.mp4`

- `productos/videos/` videos oficiales de SP Connect, 720 px, sin sonido.
- `productos/videos.json` qué video corresponde a cada producto (dirección del producto en la tienda).
